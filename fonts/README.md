# Self-hosted fonts

These are served from the site itself, so pages make no requests to Google Fonts. That avoids leaking visitor IPs, and the CSP can stay at `font-src 'self'`.

| File | Family | Weights | Source | License |
|---|---|---|---|---|
| `plus-jakarta-sans-latin.woff2` | Plus Jakarta Sans (variable) | 400–800 | Google Fonts, latin subset | SIL Open Font License 1.1 |
| `geist-latin.woff2` | Geist (variable) | 300–700 | Google Fonts, latin subset | SIL Open Font License 1.1 |
| `geist-mono-latin.woff2` | Geist Mono (variable) | 400–500 | Google Fonts, latin subset | SIL Open Font License 1.1 |
